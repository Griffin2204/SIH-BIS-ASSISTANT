# Multilingual and Regional Language Support
Add a language selector and support English plus Hindi, Marathi, Bengali, Tamil, Telugu, Kannada, Malayalam, Gujarati, Punjabi, Odia, and Assamese. Support text, voice, and PDF input. Translate questions and answers through a backend translation service such as Bhashini. Preserve IS numbers, technical terms, legal terms, standard titles, and certificate details. Persist the selected language during the session. Add translation-failure fallback and a notice that certification-critical answers must be checked against official BIS sources. Never expose API keys in the frontend.
